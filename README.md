# Milton Developer — Entregable 9

## Optimización SEO, accesibilidad y estructura semántica

Proyecto desarrollado como parte del curso de Desarrollo Web de Coderhouse.

En este entregable se trabajó la optimización del sitio web **Milton Developer**, aplicando buenas prácticas de SEO On-Page, accesibilidad y estructura semántica para mejorar la organización, comprensión y visibilidad del contenido.

## 🚀 Tecnologías utilizadas

* HTML5
* CSS3
* SCSS
* Bootstrap
* JavaScript
* Git
* GitHub

## 🔍 Optimizaciones SEO

Se realizaron las siguientes mejoras:

* Incorporación de etiquetas `<title>` descriptivas en cada página.
* Incorporación de `meta description` en todos los documentos HTML.
* Incorporación de `meta keywords` relacionadas con el contenido de cada página.
* Uso de palabras clave relevantes de manera natural.
* Optimización de la estructura jerárquica de encabezados.
* Uso de un `<h1>` principal en cada página.
* Organización correcta de los encabezados mediante `<h2>` y `<h3>`.
* Optimización de los nombres de los archivos de imágenes.
* Revisión de las rutas de las imágenes después de su actualización.

## ♿ Accesibilidad

Se realizaron mejoras orientadas a la accesibilidad:

* Incorporación de textos alternativos descriptivos mediante el atributo `alt`.
* Revisión del contraste entre textos y fondos.
* Uso de una estructura HTML semántica.
* Revisión de la jerarquía de títulos para facilitar la navegación y comprensión del contenido.
